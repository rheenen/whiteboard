# Troubleshooting

## Logs

Each launch of Whiteboard writes a folder named for its start time. `main.log`
in that folder has the app and review server logs. The folders live here:

- macOS: `~/Library/Application Support/Whiteboard/logs/`
- Linux: `~/.config/Whiteboard/logs/` (or `$XDG_CONFIG_HOME/Whiteboard/logs/`)
- Windows: `%APPDATA%\Whiteboard\logs\`

Preview builds use `Whiteboard Preview` in place of `Whiteboard`.

## Report a problem

Whiteboard sends no bug or crash reports. To report a problem, open an issue
with the maintainers of the build you use. Include your app and agent
versions, operating system, reproduction steps, and exact error text.

For questions, ask on [Discord](https://discord.gg/wYvd2cpMQg).
